# OverShoulder Camera

Mod nativo `.hnmod` para Horizon Nightly, com câmera próxima atrás do jogador, deslocamento sobre o ombro direito, suavização e mira central.

## Compatibilidade declarada
- Horizon Nightly: build `native-9f42064-dac394f91015` (13/11/2026)
- Horizon revision: `9f42064c11efe7ef3e5ed2baad7ddc2a3b36eea0`
- Game version: `26.3`
- Tecla: `F6` para alternar

## Instalação
1. Baixe `OverShoulderCamera.hnmod` na seção de arquivos do repositório.
2. Importe o arquivo pelo gerenciador de mods do Horizon Nightly.
3. Entre no jogo e pressione `F6` para alternar o efeito.

## Estado e limitações
Este pacote foi estruturado e validado quanto à integridade do arquivo ZIP e à sintaxe dos arquivos JSON/TOML. **Ainda não foi compilado nem testado dentro do Horizon Nightly.** A mira é visual; este protótipo não implementa raycast, ajuste da trajetória de projéteis, colisão da câmera com blocos nem detecção automática do modo de câmera.

Consulte `INSTRUCOES_PROXIMO_CHAT.md` para detalhes técnicos e continuidade do desenvolvimento.
